# Student Management System - Spring Boot CRUD

A simple **Student Management System REST API** built using **Java, Spring Boot, Spring Data JPA, and MySQL**.

This project demonstrates basic **CRUD (Create, Read, Update, Delete) operations** using a layered architecture.

---

## 🚀 Technologies Used

- Java 24
- Spring Boot 4.1.1
- Spring Web
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman
- Git & GitHub
- IntelliJ IDEA
